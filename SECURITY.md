# Segurança

O GMDB Saúde trata dados de saúde de cidadãos. Uma falha de segurança pode expor dados pessoais sensíveis.

## Como reportar uma falha

**Não abra uma issue pública.** Uma issue pública mostra a falha para todo mundo antes da correção.

Use o reporte privado do GitHub:

1. Abra a aba **Security** deste repositório.
2. Clique em **Report a vulnerability**.
3. Descreva a falha, como reproduzir e qual o impacto.

Só a equipe mantenedora vê o reporte. Respondemos assim que possível e avisamos quando a correção for publicada.

## Escopo

Vale para os três repositórios do sistema:

- [gmdb-backend](https://github.com/RedFoxTech/gmdb-backend)
- [gmdb-frontend](https://github.com/RedFoxTech/gmdb-frontend)
- [gmdb-pec-integration](https://github.com/RedFoxTech/gmdb-pec-integration)

Não teste falhas em ambientes de produção de municípios. Use uma instalação própria.
